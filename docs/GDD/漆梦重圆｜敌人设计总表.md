# 《漆梦重圆》｜敌人设计总表

> **定位：** 正式版候选敌人库，共 36 种普通／特殊敌人、8 种 Boss。  
> **状态：** 螺羽雀、游金龙、宝相兽为首批保留原型；其余均为候选创意，尚未定稿。  
> **总称：** 暂未确定，文中以「器中物象」作为策划代称。

## 核心设定

漆器上的花鸟、走兽、人物、山水及装饰纹样受到遗憾侵染，脱离漆面成为敌人。击败后，它们逐渐恢复为原有的工艺纹样。

---

## 01｜螺钿·花鸟与水族

**视觉关键词：** 珠光、虹彩、薄贝、轻盈、碎片化。以速度和群体行为为特色。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| **螺羽雀** ★ | 贝壳羽片组成的雀鸟，飞行时不断折射虹光 | 高速突进，接近修复核时短距离冲刺 |
| 碎光蝶 | 两片螺钿构成蝶翼，翅膀像碎镜 | 受到一定伤害后分裂为两只小蝶 |
| 贝翎鸢 | 由细长贝片构成的猛禽，翼展宽大 | 优先俯冲攻击后方防御棋子 |
| 珠尾鲤 | 通体珍珠光泽，尾部拖着细碎贝屑 | 以弧线穿行，周期性加速 |
| 星螺萤 | 极小的发光螺钿颗粒组成萤火虫 | 成群出现，单体弱但数量多 |
| 月纹鹤 | 修长的白鹤，羽翼带有月白色贝纹 | 发出短暂光幕，保护附近同伴 |

## 02｜描金·游龙与金纹

**视觉关键词：** 金线、游动、连续轨迹、勾勒轮廓。突出线条的延伸与连接。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| **游金龙** ★ | 没有实体鳞片，身体完全由流动的金线勾成 | 长身穿行，身体多个部位形成连续威胁 |
| 金络蛇 | 纤细金线缠绕而成，移动时留下金色轨迹 | 优先寻找经济建筑进行攻击 |
| 描线蛛 | 八条腿如毛笔勾线，腹部是一枚金色纹章 | 在两座防御塔之间织线，暂时干扰攻击 |
| 流金蜓 | 金线与透明薄翼构成的蜻蜓 | 快速改变移动方向，难以持续锁定 |
| 金铃燕 | 翅尖挂着细小金铃的燕子 | 周期性鸣响，使附近敌人短暂加速 |
| 卷草龙 | 由连续卷草纹交织而成的细长龙形 | 行进中伸展卷草枝蔓，制造额外目标 |

## 03｜百宝·奇珍走兽

**视觉关键词：** 玉石、玛瑙、珊瑚、绿松石、厚重的镶嵌层次。突出材质差异。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| **宝相兽** ★ | 玉石躯干、玛瑙甲片、珊瑚角共同组成的灵兽 | 重装敌人，外层镶片逐步破碎，防御阶段性下降 |
| 玉枝鹿 | 通体白玉，鹿角化作盛开的玉兰枝 | 为身边敌人提供短暂保护 |
| 珊瑚狐 | 红珊瑚构成的灵狐，尾巴像分枝珊瑚 | 生命较低时，分出数只小型珊瑚狐 |
| 玛瑙犀 | 深红玛瑙构成的厚甲犀兽，犀角像磨制宝石 | 蓄力撞击特定防御建筑 |
| 松石龟 | 绿松石龟甲，表面嵌着细小山水纹 | 背负小型敌人，受到攻击时释放 |
| 碧玉猊 | 碧玉雕成的狮形瑞兽，颈部佩有金环 | 发出威吓，使附近防御塔短暂降低攻击频率 |

## 04｜花木与山水

**视觉关键词：** 花枝、藤蔓、山石、亭台、流水。适合具有完整山水花鸟构图的漆器。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| 玉兰蝶 | 花瓣拼成双翼的蝴蝶，飞行时不断落瓣 | 留下花粉区域，短暂遮蔽防御塔视线 |
| 金枝鹿 | 身体由纤细枝条构成，角上生有金色嫩叶 | 经过同伴时为其提供恢复效果 |
| 石纹猿 | 仿佛从漆屏山石纹样中跳出的灵猿 | 跳跃越过局部火力区，优先靠近高价值建筑 |
| 柳丝鸢 | 长尾如垂柳丝线的纸鸢鸟 | 拖拽附近小型敌人，使队形突然改变 |
| 云桥燕 | 从云纹与楼阁间飞出的燕子 | 短暂制造云影，掩护附近敌人 |
| 莲心童 | 莲花纹中诞生的小小人形，举着荷叶 | 为附近同伴撑起小范围防护伞 |

## 05｜人物、戏台与器中故事

**视觉关键词：** 戏曲、剪影、人物画、衣袖、折扇、灯影。适合叙事性较强的器物。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| 灯影伎 | 身体像一片半透明的漆画剪影，衣饰精美 | 投下与自己相似的影子，干扰防御目标选择 |
| 空袖伶 | 漆面戏曲人物活化，双袖如流动长绸 | 用水袖缠住附近防御塔，短暂限制其行动 |
| 画中童 | 原本位于人物画边缘的小童，抱着一盏灯 | 召集附近小型敌人集中进攻 |
| 折扇客 | 身着长衫的人物纹样，手持金边折扇 | 展扇形成正面防护，改变受击效果 |
| 纹窗偶 | 亭台窗棂与人物剪影拼成的木偶 | 站定后向周围投出多个小型影偶 |
| 戏面傀 | 脸上具有两副戏曲面具的机关人物 | 随生命变化切换快速与重装两种形态 |

## 06｜特殊纹样与漆层异象

**视觉关键词：** 幻想化的漆层、纹样与材质状态。适用于特殊器物、精英敌人和视觉奇观，不必强行对应实际漆艺病害。

| 名称 | 形象设计 | 战斗机制 |
|---|---|---|
| 剥纹犬 | 身上的漆纹如薄片层层掀起，露出不同颜色的躯体 | 每失去一层外壳，移动速度提高 |
| 陷彩傀 | 身体由雕刻凹槽与填色纹样构成的傀儡 | 在地面留下延迟触发的纹样区域 |
| 漆浪魇 | 犀皮层纹形成的流动生物，身体如漩涡 | 释放波纹，干扰附近防御单位 |
| 斑纹魍 | 不断变换黑、红、褐色层纹的无面兽 | 随时间改变对不同攻击的抵抗效果 |
| 点星群 | 大量微小点螺嵌片凝成的星屑群 | 聚合时坚固，分散时形成大量小型单位 |
| 返彩蛾 | 翅膀上的彩色图案一层层褪去，又重新浮现 | 受到连续攻击时短暂改变自身状态 |

## 07｜Boss 候选总表

Boss 是对应漆器纹样中最重要、最有象征意义的物象，同时与该关遗憾的情感核心有关。

| Boss | 视觉形象 | 战斗特色 | 适配故事 |
|---|---|---|---|
| **失羽凤** | 华丽的百鸟之首，羽毛逐片脱落，露出未完成的螺钿骨架 | 召集飞鸟、羽片散射、阶段性重组 | 等待、离别、失去 |
| **断金游龙** | 巨大的描金龙盘绕战场，躯干的金线不断断裂、重接 | 金线分割战场、持续穿行、多段躯体攻击 | 断裂的约定 |
| **百宝麒麟** | 不同宝石嵌片组成的巨兽，随着战斗层层解体 | 多层装甲，失去不同材料后改变攻击行为 | 珍藏、守护、执念 |
| **空台伶王** | 立于虚幻戏台之上的巨大戏曲人物，面具不断改变 | 戏台灯影、分身、幕布遮蔽与舞台切换 | 未完成的演出 |
| **枯荣花主** | 半身盛放、半身凋零的巨大花木精灵 | 花枝蔓延、花瓣群袭、开放与凋零双阶段 | 错过、等待、重逢 |
| **千螺星鲲** | 无数螺钿星点凝成的巨鱼，游动时仿佛一片流动星空 | 聚散形态、鱼群冲击、大范围星屑攻击 | 远行、未能抵达的归途 |
| **金面山君** | 由金纹勾勒的虎形守护兽，面部像一张古老的漆画面具 | 高速扑袭、威吓、战场区域压制 | 保护与失守 |
| **未竟画师** | 由大量残缺人物纹样与金线组成的巨大工匠剪影 | 调动不同纹样敌人，改变战场构图 | 未完成的作品与承诺 |

> **说明：** 上述 Boss 均为虚构角色设计。具体关卡选型应与器物纹样和故事相符。

## 08｜器物与敌人生态对应

正式版的不同漆器拥有各自的纹样生态，不应让所有敌人在所有关卡中无差别混合出现。

| 器物主题示例 | 修复核／信物 | 代表敌人 | 核心 Boss |
|---|---|---|---|
| 花鸟纹漆盒 | 一封未寄出的信 | 螺羽雀、碎光蝶、月纹鹤 | 失羽凤 |
| 描金龙纹漆屏 | 一枚约定信物 | 游金龙、金络蛇、描线蛛 | 断金游龙 |
| 百宝嵌珍藏盒 | 一只旧耳坠 | 珊瑚狐、玉枝鹿、宝相兽 | 百宝麒麟 |
| 戏曲人物纹漆盘 | 一张旧戏票 | 灯影伎、空袖伶、戏面傀 | 空台伶王 |
| 山水花木纹漆柜 | 一枚旧书签 | 柳丝鸢、云桥燕、玉兰蝶 | 枯荣花主 |

## 09｜命名原则与首批优先原型

- **有形象：** 玩家听到名字，就能大致想象它的外观。
- **有材质：** 贝、螺、金、玉、珊瑚等元素自然融入名称。
- **有诗意，不过度生造：** 保留东方奇幻气质，避免大量重复使用「魇」「煞」等后缀。

**首批优先发展的敌人：**

1. **螺羽雀**：轻快、灵动、快速突进。
2. **游金龙**：线性、延展、连续穿行。
3. **宝相兽**：厚重、多材质、分层破甲。
